# Ideas parking lot

Ideas that are **out of scope for this repository**. Writing them here lets you stop thinking
about them without starting them. Revisit only after [DONE.md](DONE.md) is complete.

## Future handbooks (separate repositories, same schemas)

Each future handbook copies `CONTRIBUTING.md` and `templates/` from this repository, so all
handbooks share the same five document types and front matter.

| Handbook | Notes | Status |
|---|---|---|
| Data science | Lifecycle (CRISP-DM), data cleaning cards, statistical method cards, ML algorithm cards, decision trees ("which test?", "which model?", "which metric?"), project starter based on Cookiecutter Data Science | parked |
| Agentic AI | Agents, tools, guardrails, MCP, multi-agent and human-in-the-loop patterns (RAG, model serving and evaluation basics already live in this playbook) | parked |
| Remote sensing | Sensors, spectral indices, coordinate reference systems, COG / STAC / Zarr / GeoParquet, change detection | parked |
| Precision agriculture | Field boundaries, crop monitoring, yield modelling, variable-rate prescriptions, agronomic data sources | parked |
| Mathematics | Linear algebra, probability, optimization, as method cards with notation and proofs sketched | parked |

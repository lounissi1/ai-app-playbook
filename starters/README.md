# Starters

Real, copyable files. Docs elsewhere in this repository stay cloud-neutral; files here are
specific to one cloud.

| Folder | Status |
|---|---|
| [`azure/`](azure/) | In progress: first implementation |
| `aws/` | Not started (see `IDEAS.md`) |
| `gcp/` | Not started (see `IDEAS.md`) |

Every starter folder has a `README.md` that follows the starter schema in `CONTRIBUTING.md`,
including a **Proven on** section. A starter is only trusted once that section names a real
project and date.
